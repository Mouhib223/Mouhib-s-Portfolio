## ✨ Key Features

- **Pure Web Architecture:** Zero frameworks, npm packages, or build processes required.
- **Data-Driven Content:** Dynamic rendering of experiences, projects, certifications, education, and languages via `assets/js/data.js`.
- **Dark / Light Theme:** Persistent theme toggling powered by CSS variables and `localStorage` with system preference detection (`prefers-color-scheme`).
- **Fully Responsive & Accessible:** Built with semantic HTML5, explicit focus management, ARIA attributes, and keyboard navigation support.
- **Performance Optimized:** Lightweight asset delivery, native smooth scrolling, and motion accessibility (`prefers-reduced-motion`).

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties & Grid/Flexbox), JavaScript (ES6+ Vanilla)
- **Typography:** Inter (Primary UI), JetBrains Mono (Code/Labels)
- **Icons:** Inline vector SVGs
- **Hosting:** GitHub Pages
